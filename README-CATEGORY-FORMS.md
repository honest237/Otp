# Category forms update

Copy the `src` folder from this zip over your project's `src` folder (merge, overwrite when asked). No database change is needed. Commit, push and redeploy.

New: per-category product forms (proxies, social accounts, subscriptions, digital products),
stock slots, country on listings, ebook/video-course/link/license-key delivery, and structured
delivery on the customer's purchase page.

Video lesson uploads need Supabase Storage (supabase/storage-media.sql) to be applied.
